# Voice Assistant

## Запуск

Нужен Python 3.12. В терминале из корня проекта установите зависимости,
запустите локальную базу данных, затем стартуйте Reflex:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
docker compose up -d postgres redis
cd frontend
reflex run
```

Откройте адрес, который напечатает `reflex run`. Не запускайте второй экземпляр
Reflex параллельно: если порт занят, Reflex выберет другой и сам передаст его
фронтенду. Эта конфигурация нужна и для запросов микрофона.

Для запросов ассистента нужны доступная PostgreSQL и заполненный `.env`.
Укажите `GIGACHAT_CREDENTIALS` для ответов через GigaChat. Без ключа простые
команды обрабатываются встроенным NLU-режимом. При открытии страницы Reflex
заранее загружает модели поиска, распознавания и озвучивания; дождитесь, пока
сообщение о подготовке моделей исчезнет. Запись отправляется кнопкой микрофона,
переключатель громкости рядом с ней включает или отключает озвучивание ответов.
Календарь и недельная загруженность читаются из `events` в PostgreSQL при запуске.
PyAV для декодирования записи с микрофона установится вместе с остальными
зависимостями.

Код интерфейса находится в `frontend/`: `app.py` запускает Reflex,
`frontend_core/state.py` содержит состояние, `frontend_core/components/`
содержит элементы чата и календаря, а `frontend_core/assistant_service.py` и
`frontend_core/audio_api.py` отвечают за связь с ассистентом и обработку аудио.
